* Reading data from a file
Two important information is needed before reading the file
- the filename of the data (~populations.txt~ in this example)
- the folder where it resides in the computer (generally as same as the working ~.py~ file)

Then we can use ~np.loadtxt~ function in our script

#+BEGIN_SRC python
data = np.loadtxt("populations.txt", skiprows=1)
#+END_SRC

where ~skiprows~ parameter is needed to disregard the first line.

* Writing data into text files
We generally write numerical data into text files.

From the previous example let's create a 1D array where the each element corresponds to the average of the temperature values at each scan

#+BEGIN_SRC python
data_temp_mean = np.mean(data_temp, axis=1)
#+END_SRC

Let's write ~data_temp_mean~ array into a file called ~average.txt~,

#+BEGIN_SRC python
np.savetxt("average.txt", data_temp_mean)
#+END_SRC

* Remarks
- File read/write operations can be done in or out of function definitions
- 2D arrays can also be written into text files
- ~.csv~ files are very similar to ~.txt~ files, but the values inside ~.csv~ are generally separated by commas
