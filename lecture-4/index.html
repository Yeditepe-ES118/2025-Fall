Formatted output

  • Strings are sequence of characters: "this is a string of characters"
  • We can put different variables in strings by formatting
  • Numerical values can be used inside a string with its format specified

Let's break it down:

  • %: the specifier (first one)
  • 7: the minimum width of the numerical output
  • 2: the number of the fractional digits
  • .: separates the whole and the fractional digits
  • f: the floating-point notation
  • \n: the newline character
  • %: the separator (second one)
  • x: the substituted variable

Remarks on functions

We've seen defining functions in assignments, and their use.

Let's summarize and make some remarks.

There can be four types of function definitions: 

def myfunction(parameters):
    function-block
    return variables

def myfunction(parameters):
    function-block

def myfunction():
    function-block
    return variables

def myfunction():
    function-block
  • a script may have several functions
  • a function can be called in another function
  • contents of the function are established by indentation
